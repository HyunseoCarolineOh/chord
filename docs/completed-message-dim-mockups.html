완료된 메시지 dim — 5안 비교

각 카드에 같은 메시지 흐름이 들어 있고, 3개는 이미 완료 상태입니다. 마우스 hover로 어떻게 펼쳐지는지 확인하세요.

[A]Strong dim
현행 강화 — opacity 0.18로 거의 흐려지고 hover 시 0.7로 살아남. strike 유지. 가장 단순.
[B]One-line ellipsis
완료된 메시지는 한 줄로 압축되고 끝에 …로 잘림. hover 시 펼쳐짐. 헤더(시각/작성자)는 또렷.
[C]Header-only
본문 완전 숨김 — 시각/작성자 strike 한 줄만 남음. hover 시 본문 슬라이드 다운. 가장 강력하게 압축.
[D]Phantom (거의 투명)
opacity 0.08 — 거의 사라진 유령처럼. 위치는 차지하지만 시선엔 안 잡힘. hover로만 읽힘.
[E]Ghost line (요약 한 줄)
메시지 전체가 사라지고 "✓ 본문 첫 몇 글자…" 한 줄짜리 ghost로 압축. hover 시 풀버전 펼침.

5안 trade-offs

안안 보임 정도읽기 비용레이아웃 영향구현실수 시 회복
[A] Strong dim 중 0 (그냥 보임) 없음 (높이 유지) 매우 낮음 (opacity만) 즉시 다시 클릭
[B] One-line 중~높음 hover 1번 높이 ↓ (1줄) 낮음 (CSS only) 즉시
[C] Header-only 매우 높음 hover 1번 + 펼침 대기 높이 크게 ↓ 낮음 hover 후 클릭
[D] Phantom 매우 높음 hover 필요 없음 (높이 유지) 매우 낮음 즉시
[E] Ghost line 높음 hover 1번 + 펼침 대기 높이 크게 ↓ 중 (data-summary 채워야) hover 후 클릭
"안 보였으면"이 시각 노이즈 최소[D] Phantom — 자리만 차지하고 거의 사라짐. 가장 단순한 추가 변경.
"안 보였으면"이 공간까지 줄임[C] Header-only — 한 줄로 압축, hover 시 슬라이드 다운. 스크롤 길이 크게 절약.
절충안[B] One-line — 본문 요약은 보이되 한 줄로 잘림. 헤더 또렷.
