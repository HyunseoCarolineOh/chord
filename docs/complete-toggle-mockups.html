chord 완료처리 UX — 5안 비교

각 카드의 메시지를 직접 클릭해 보세요. 상태는 새로고침해도 유지됩니다.

[01] Hover ✓ chip
메시지 hover 시 우측에 작은 ✓ 버튼이 나타남. 평소엔 안 보임 → 노이즈 0.
[02] Status dot
메시지 왼쪽에 작은 dot — 비어있다가 클릭하면 형광 그린 글로우로 채워짐. 항상 보임.
[03] 좌측 마진 클릭 → strike
메시지 왼쪽 18px 마진이 클릭 영역. hover 시 시안 라이트 → 클릭 시 그린 사이드 바 + 본문 취소선.
[04] Reaction ✅
Slack 스타일. 메시지 아래 ✅ 반응이 칩으로 토글. 추가 = 완료. 다른 사람 reactions와 통일된 UI.
[05] Inline _mark done_
메시지 뒤에 markdown italic 토큰 _mark done_. 클릭하면 _✓ done_ 으로 변함. 터미널 미감과 가장 잘 맞음.

5안 trade-offs

안 발견성 클릭 비용 시각 노이즈 구현 난이도 chord 미감
[01] Hover ✓ 중 (호버 시만) 1클릭 0 (평소 안 보임) 매우 낮음 (CSS only) 중
[02] Status dot 높음 (상시 표시) 1클릭 낮~중 (dot 상시) 매우 낮음 높음 (terminal cursor)
[03] 좌측 마진 낮음 (영역 모호) 1클릭 0 낮음 중
[04] Reaction ✅ 중 2클릭 (열고 ✅) 중 (chip 상시) 중~높음 (스키마 확장 필요) 낮음 (이모지 톤 충돌)
[05] Inline _done_ 중~높음 1클릭 낮~중 (텍스트 토큰) 낮음 매우 높음 (markdown 톤)
기본 추천[02] Status dot — 발견성/노이즈/미감 균형.
미감 우선[05] Inline _done_ — markdown 터미널 톤과 가장 자연스럽게 어울림.
노이즈 최소[01] Hover ✓ — 메시지 흐름을 절대 방해하지 않음.
